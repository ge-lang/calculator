# 🧮 Advanced Scientific Calculator

A fully-featured scientific calculator with multiple modes, history tracking, and advanced mathematical functions.

![Calculator](https://via.placeholder.com/800x400/e67e22/ffffff?text=Calculator)

## ✨ Features

- **Multiple Modes** - Basic, scientific, programmer
- **Advanced Functions** - Trigonometry, logarithms, exponents
- **Calculation History** - Review past calculations
- **Memory Functions** - M+, M-, MR, MC
- **Keyboard Support** - Full keyboard operation
- **Responsive Design** - Mobile calculator
- **Theme Support** - Light/dark modes

```bash
# Open index.html to use calculator
```

🔧 Supported Operations

Basic Operations

· Addition, subtraction, multiplication, division
· Percentage calculations
· Square roots, exponents

Scientific Functions

· Trigonometric functions (sin, cos, tan)
· Logarithms (log, ln)
· Constants (π, e)
· Factorials, powers

Programmer Mode

· Binary, octal, decimal, hexadecimal
· Bitwise operations
· Logical functions

⌨️ Keyboard Shortcuts

```
Numbers: 0-9
Operators: +, -, *, /
Functions: s (sin), c (cos), t (tan)
Enter: Calculate
Escape: Clear
```
